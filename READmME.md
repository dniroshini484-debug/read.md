# Paradise Nursery - Online Plant Shop

Paradise Nursery is a dynamic React and Redux-based e-commerce web application where plant lovers can browse categorized houseplants, view product details, manage their shopping cart, and seamlessly track order costs in real time.

## Project Structure & Key Features
* **Landing Page:** Features background imagery, company mission statement, and entry navigation.
* **Product Catalog:** Categories featuring Air Purifying, Aromatic, and Medicinal plants with interactive state tracking.
* **Redux Shopping Cart:** Global state tracking item counts, dynamic subtotal calculations, increment/decrement controls, and cart badge updates.

## Tech Stack
* **Frontend:** React.js, Vite / Create React App
* **State Management:** Redux Toolkit (`@reduxjs/toolkit`, `react-redux`)
* **Styling:** CSS3, Flexbox & CSS Grid
